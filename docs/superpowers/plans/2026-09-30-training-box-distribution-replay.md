Goal: obtain independently verified native class dimensions and center-Z distributions from all 64 training scenes before choosing scientific anchors. This is preparation for ticket 07, not anchor adoption or a trained result.

Inputs: `experiments/waymo-perception/research/training-box-statistics-inputs.candidate.json`, the original acquisition/cohort manifests, and the generation-pinned source receipts. The candidate inventories 726,715 native rows in 47,802,105 source bytes; the largest source is 1,800,998 bytes. These are metadata counts, not replay results.

1. After the current queue finishes, recheck its authoritative process/session state. Rehash both manifests and every selected receipt. Combine the acquisition manifest with its excluded engineering scenes and call existing `admit_scene` using all 17 component receipts for each selected scene. Require exactly the original 64 training-only scenes. Do not infer membership from filenames.
2. Use existing `staged_source` and the shared cache-level lease for one LiDAR-box source at a time. Recompute retained engineering raw bytes and enforce the combined 2 GiB limit. Use the sibling Waystone wrapper and verify declared size, SHA256 and GCS MD5 before exposing bytes to Insula. Do not fetch the multi-GB sidecar archives for this task.
3. In locked offline CPU Insula, decode Arrow rows with native keys `key.segment_context_name`, `key.frame_timestamp_micros`, and `key.laser_object_id`. Read `[LiDARBoxComponent].type` and the seven fields `box.center.x/y/z`, `box.size.x/y/z`, `box.heading`. Preserve native length/width/height/center-Z; no ROI clipping, bottom-Z conversion, or repeated-track deduplication.
4. Keep a completed-source ledger separate from nonempty row statistics. Reconcile decoded total rows with each admitted source inventory, explicitly count any category outside native box classes 1–4, and record zero-eligible-row sources as completed. Reject duplicate frame/object keys and invalid finite/positive geometry. A source exception invalidates the aggregate; partial results cannot become adopted anchors.
5. Run `training_box_statistics` on eligible rows with admitted training membership. Record per-class row and unique-track counts, medians, linear p10/p90 quantiles, and absent classes as null. Bound aggregation memory explicitly and measure peak RSS and elapsed time on the real cohort.
6. A separate live checker reopens every immutable source sequentially, independently collects length/width/height/center-Z, sorts each class/coordinate, and computes median and linear quantiles without invoking the producer statistics function. Reconcile all source completions, row/category counts, identities, distributions, and source hashes. Retain input/output/runtime/code hashes, commands, logs and resource measurements in a receipt.

Acceptance: all 64 sources independently replayed; no engineering/development/held-out source used; complete row accounting including empty eligible sources; independent distribution agreement; locked TensorFlow-free live receipts; staged raw cleaned and recovery identities retained. Missing classes do not acquire default dimensions. Choosing templates, orientation policy, ROI, sampling caps, assignment thresholds and training budgets remains a separate preregistration decision.
