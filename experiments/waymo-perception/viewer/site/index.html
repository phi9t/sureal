Waymo Perception Viewer

A browser-based 3D viewer for Waymo Open Dataset Perception v2.0.1 scenes: five LiDARs fused into one point cloud, five calibrated cameras with their images in place, 3D and 2D labels, panoptic and LiDAR segmentation, human keypoints, the ego trajectory, and temporal accumulation, rendered with Three.js from bundles exported by a small PyArrow/NumPy pipeline. No TensorFlow, no Waymo SDK.

Open the viewer Source on GitHub
Waymo Open Dataset data is licensed for non-commercial research and may not be redistributed, so this page hosts only the viewer. Bundles are exported and served from your own machine; the hosted viewer loads them over a loopback URL.

Run it on your data

git clone git@github.com:phi9t/sureal.git && cd sureal
V=experiments/waymo-perception/viewer/run.sh
$V setup                                   # uv venv + npm ci
$V export "$SLICE_DIR" "$CONTEXT"          # ~40 s and ~1 GB per 20 s scene
$V verify "$SLICE_DIR" "$CONTEXT"          # independent geometry and hash checks
$V dev                                     # local app at http://127.0.0.1:5173/
$V build && $V serve                       # or serve bundles for the hosted viewer

With run.sh serve running, open the hosted viewer and paste http://127.0.0.1:8420/bundles/<slice>/<context>/. The slice is the Parquet component layout of the official v2.0.1 release ({component}/{context}.parquet) plus a slice.json receipt.

What the exporter does

  • Converts each range image to points with the pinned upstream equations: half-pixel inclinations, row 0 as the top beam, azimuth corrected by the extrinsic yaw, and per-pixel Rz·Ry·Rx motion compensation for the TOP LiDAR.
  • Stores points in the vehicle frame as int16 at 5 mm in a planar binary container, so temporal accumulation is just a per-frame pose on the GPU.
  • Bakes camera colour onto every point through Waymo's own lidar_camera_projection, which keeps the colours distortion-correct.
  • Passes JPEGs and 16-bit panoptic PNGs through byte-for-byte and records SHA-256 lineage back to the source Parquet files.
